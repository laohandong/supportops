# 升级后配置核查

适用于升级后行为变化、配置不生效和资料版本冲突。

1. 读取当前部署版本，核查用户描述的变更时间与影响范围。
2. 同时检查提供的配置和运行时生效值，不能仅凭文件中存在某个键认定其生效。
3. 检索当前版本的迁移说明和配置文档，检查默认值、废弃键、路径与认证要求。
4. 将生效值与真实请求日志、下游返回对照；引用具体配置规则及其来源。
5. 旧版案例只能提供线索。若缺少适用文档，应请求材料，不推定新版本兼容旧规则。
6. 提出最小人工变更建议。检查已检索资料是否包含当前版本的业务恢复验证；缺少时，使用 search_knowledge 单独补查业务操作的恢复验证与成功响应条件。
7. 依据检索原文写明变更后的复验动作、新请求标识、响应状态及业务成功字段，引用其来源。配置已生效或旧错误消失不等于业务恢复；变更后应重新获取业务请求证据，不复用变更前结论。资料缺失或检索失败时说明未核实的标准，不编造具体值；复验失败时保留新请求和响应供继续排查。
