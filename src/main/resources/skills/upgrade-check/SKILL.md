# 升级后配置核查

适用于升级后行为变化、配置不生效和资料版本冲突。

1. 读取当前部署版本，核查用户描述的变更时间与影响范围。
2. 同时检查提供的配置和运行时生效值，不能仅凭文件中存在某个键认定其生效。
3. 检索当前版本的迁移说明和配置文档，检查默认值、废弃键、路径与认证要求。
4. 将生效值与真实请求日志、下游返回对照；引用具体配置规则及其来源。
5. 旧版案例只能提供线索。若缺少适用文档，应请求材料，不推定新版本兼容旧规则。
6. 提出最小人工变更建议，说明验证请求与成功标准；变更后重新查询，不复用变更前结论。
