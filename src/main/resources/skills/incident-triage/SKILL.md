# 集成故障初诊

适用于同步失败、认证失败、下游不可用等集成报障。

1. 确认当前应用、部署版本和影响操作。
2. 查询最近调用日志，记录请求标识、响应状态和路径。无法获取日志时保留证据缺口。
3. 将下游健康状态与业务请求结果区分：健康接口可用不代表认证和业务路径正确。
4. 查询生效配置；仅记录脱敏结果，不索要或输出凭据原文。
5. 对自定义错误码、配置行为和接口规则查询适用版本的文档。
6. 用现场事实验证候选原因，列出人工下一步与恢复检查。避免重复失败请求和无依据的重启建议。

输出事实、候选原因、建议和待补充信息，并关联工具与文档来源。工具失败不能视为被查询系统不存在或已经恢复。
