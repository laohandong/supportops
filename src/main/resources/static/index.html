            统计口径与阅读说明
            

                
日期范围包含首尾，最多 90 天；按诊断创建时间归属。UTC 比北京时间晚 8 小时，图表和排行使用相同范围。

                
Token 仅含对话模型已报告的输入与输出，不含向量用量或费用。未报告不代表零消耗，已有报告也可能仅覆盖部分调用；累计曲线从所选范围起点重新累计。

                
每轮平均消耗 = 该时段已报告总 Token ÷ 该时段全部诊断轮数，无诊断时留空。完成轮数仅表示 COMPLETED 状态，不代表回答正确。会话回看包含所选日期之外的全部历史。
