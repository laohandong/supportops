# OrderBridge 1.0 到 2.0 配置迁移

## 迁移要求

适用于 OrderBridge 2.0。升级后必须将订单路径配置键由 `orders.path` 迁移为 `sync.targetPath`。旧键在 2.0 中被忽略，缺少新键时默认使用 `/v1/orders`。

当前下游接入路径为 `/v2/orders`，因此升级后的目标配置是 `sync.targetPath=/v2/orders`。请由实施人员核查部署配置的来源与生效值；本文是迁移规则，不代表任意现场故障都由该配置导致。

## 排查依据

要验证配置迁移是否与当前失败有关，需要同时取得部署版本、提供的配置、生效配置、失败请求路径和下游响应。某一项缺失时应保留假设，不将文档规则直接当作现场根因。

## 操作与检查

在本地示例环境中，由人员使用“应用 2.0 路径配置”操作修正配置并触发一次同步。在其他部署中必须由对应环境的授权人员执行。处理后检查新的业务响应、请求标识和生效值。
