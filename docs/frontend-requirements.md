# SupportOps 前端需求说明

版本：1.1 · 整理日期：2026-10-19
用途：定义 SupportOps 纯前端原型的业务范围、交互状态和验收要求。原型独立运行，使用合成数据；本说明不代表原型已集成到当前工作台。

本说明依据当前工作区的页面结构、前端脚本和样式整理，包含登录、诊断及现有后台页面。正文可以单独交给生成工具使用，不要求接收方读取原仓库。现有功能以页面代码为依据；本文是前端生成要求，不代表现有部署已完成全部浏览器验收。

## 1 目标与范围

### 1.1 产品定位

SupportOps 面向软件实施与技术支持人员。用户描述现场问题，诊断助手展示排查过程、适用文档与现场证据，人员核实建议并回填处理结果。管理员负责资料、配置、账号、企业接入、脱敏来源导出和受控修复。评测平台由独立项目提供。

主要使用场景是客户报障之后、研发深入处理之前的初步排查。界面应体现技术工作台的可读性与操作效率，让用户随时看清：正在处理什么、依据是什么、当前做到哪一步、还需要人员做什么。

### 1.2 本次需要交付的内容

交付一个可独立启动的纯前端应用，覆盖本文所有页面及主要交互。使用本地合成数据和可控的异步模拟，使登录、诊断、资料处理、来源导出、修复等流程能够连续演示。

| 包含 | 不包含 |
| --- | --- |
| 页面、导航、布局、表单、列表、图表、对话框、详情、状态反馈 | Java、Spring Boot 或其他后端服务开发 |
| 模拟账号与角色切换、前端可见范围 | 真实认证、密码加密、服务端鉴权 |
| 模拟流式输出、任务进度、失败、取消和恢复 | 真实模型调用、MCP 工具执行、现场诊断 |
| 模拟文件上传、解析结果、文档与 Excel 展示 | 真实文件解析、对象存储、向量索引、SQL 执行 |
| 浏览器内的数据联动、草稿保存、历史与模拟导出 | 数据库、迁移、后台任务、容器和运维脚本 |
| 企业接入、密钥、飞书与修复的交互演示 | 真实企业连接、密钥签发、消息发送和系统修改 |

不扩展完整工单、组织架构、多级审批、计费、多 Agent 编排、技能市场或自动修复平台。已有的“修复中心”只保留固定合成场景的人工审批与执行展示。

### 1.3 统一比较原则

1. 各实现采用相同业务范围，不以减少页面换取视觉完成度。
2. 不限定前端框架或组件库；需提供可复现的启动方式。
3. 页面名称、关键字段、角色边界和状态含义固定；布局、组件组织、字号、间距、图标与色彩可以自行设计。
4. 当前界面为浅色、低饱和绿色的专业工作台，可作为参考，不要求逐像素复刻。
5. 不要求保留现有 DOM 标识、脚本组织或内部接口路径；不定义新的后端接口。
6. 不同作品使用相同的演示主线和验收步骤。模拟延迟、异常切换和重置数据属于本次比较用要求，不应描述为现有产品已实现功能。

## 2 用户角色与信息结构

### 2.1 角色

| 身份 | 可见范围 | 关键限制 |
| --- | --- | --- |
| 未登录 | 登录、首次管理员初始化 | 不展示诊断历史或管理页面内容 |
| 普通用户 | 诊断工作台、新建会话、本人历史、本人处理结果 | 只选择获准的诊断环境；不显示后台入口和管理员修复证据 |
| 管理员 | 全部页面、可见用户的诊断记录 | 查看他人的会话时不能冒充原用户继续发送；需要新建自己的会话 |

角色在纯前端作品中由模拟身份数据决定。隐藏入口和拦截导航用于演示权限体验，不构成真实安全权限。

### 2.2 页面清单

| 编号 | 页面或区域 | 入口 | 主要目的 |
| --- | --- | --- | --- |
| F01 | 登录与首次初始化 | 独立入口 | 进入工作台或创建首个管理员 |
| F02 | 诊断工作台 | 客户工作区 | 提问、查看回答、核对证据、回看历史 |
| F03 | 处理结果 | 诊断页内的当前轮次区域 | 人员回填、验证说明、修订历史 |
| F04 | 知识文档 | 后台管理 | 上传、修订、处理记录、检索及 Excel 查询 |
| F05 | 项目约束 | 后台管理 | 管理人员确认的项目事实和限制 |
| F06 | 示例环境 | 后台管理 | 切换合成故障条件、观察环境事实 |
| F07 | 用量分析 | 后台管理 | 查看消耗趋势、排行并回看问答 |
| F08 | 模型配置 | 后台管理 | 独立维护对话模型与向量服务 |
| F09 | 用户管理 | 后台管理 | 创建账号和查看用户列表 |
| F10 | 企业接入 | 后台管理 | 项目、系统、环境、连接、授权和应用密钥 |
| F11 / F12 | 原评测与案例页面编号保留 | 无本项目页面 | 已由独立项目维护，本原型不实现 |
| F13 | 修复中心 | 后台管理、诊断及示例环境入口 | 提案、审批、模拟执行、验证与审计 |
| F14 | 飞书机器人 | 后台管理 | 查看连接、绑定账号和消息投递状态 |

共 11 个页面级入口；F03 是诊断页内的功能区域，不必单独做一级导航。

### 2.3 应用外壳

- 侧栏：SupportOps 品牌、客户工作区、新建会话、最近诊断、后台管理分组。
- 后台菜单包含知识文档、项目约束、示例环境、用量分析、模型配置、用户管理、企业接入、修复中心、飞书机器人。
- 顶栏：当前工作区域、产品或环境上下文、用户名、角色、退出入口。
- 全局反馈：成功、失败、配置缺失、加载失败等提示；重要错误应保留在相关表单或页面附近。
- 当前导航必须清晰；长侧栏在短窗口中也能滚动到全部入口。
- 页脚或折叠区可保留管理员运行信息：应用版本、运行阶段、端口、程序摘要和运行标识。前端展示合成值，读取失败显示无法核实。
- 模拟版本应在应用外壳明确显示“前端演示 · 合成数据”，不以真实连接成功或真实业务已执行的口吻报告结果。

## 3 页面详细需求

### F01 登录与首次初始化

**结构：** 居中的单列表单、品牌说明、可见字段标签、帮助文字、错误区和主按钮。

| 字段 | 规则 |
| --- | --- |
| 用户名 | 必填，3–32 位字母、数字或下划线；不区分大小写 |
| 登录密码 | 必填，隐藏输入；最长 128 字符；不要用创建密码的最小长度阻止既有账号登录 |
| 首次创建密码 | 必填，12–128 字符 |
| 部署初始化口令 | 仅在首次初始化且模拟配置要求时显示，隐藏输入 |

**交互：** 初始化读取时禁用提交；根据状态切换“登录工作台”和“创建首个管理员”。提交显示忙碌状态；成功进入诊断工作台并清空敏感输入。退出回到登录页并清除当前账号的页面临时信息。

**必备状态：** 正常登录、初始化、连接失败、用户名或密码错误、用户名格式错误、尝试过多、管理员已被其他操作创建、登录失效。

不增加公开注册、短信登录、找回密码或第三方登录。提供合成管理员和普通用户的演示进入方式，放在演示说明中，不冒充真实账号体系。

### F02 诊断工作台

**桌面结构：** 左侧对话主区、右侧证据区；输入区位于对话列底部。消息、长证据分别滚动；窄屏保证输入和证据都可到达。

**空状态：** 显示“从一个现场问题开始”、问题描述提示，以及“升级后订单同步失败”的示例入口。点击示例只填入输入框，由用户明确发送。

**输入与操作：**

| 控件 | 规则 |
| --- | --- |
| 诊断目标 | 必选，显示“项目 / 系统 / 环境 · 产品版本”；没有可用环境时说明原因 |
| 问题描述或补充信息 | 必填，最多 6000 字符，多行输入 |
| 仅关键词检索 | 可选；选择后模拟关键词模式 |
| 发送 | 目标有效、模型已配置、当前会话可继续且没有活动诊断时可用 |
| 取消诊断 | 排队或执行中显示；点击进入取消流程 |
| 刷新诊断 | 进度读取或连接异常后可用；仅恢复读取 |
| 导出诊断 | 选中已结束的轮次后导出当前诊断 JSON |
| 创建修复提案 | 管理员在已结束的轮次可进入；适用性在提案预览中说明 |

同一会话的诊断目标保持一致。切换目标需要新建会话，不能把不同环境的问答拼接在同一会话中。模型未配置时，管理员获得模型配置入口；普通用户看到联系管理员的说明。

**对话展示：**

- 区分用户与助手消息，支持多轮问答和逐段输出。
- 回答支持标题、列表、表格、代码块和引用。长代码、表格局部横向滚动。
- 输出中显示进行中的状态，终态后展示完整回答；取消或失败时保留已生成内容，并标明它是不完整草稿。
- 内容组织应能分辨已确认事实、候选原因、处理建议和证据缺口，不要求每次自然语言完全相同。
- 用户正在阅读上方内容时不强制滚动到底部；接近底部时可跟随新内容。
- 标题过长允许截断，完整问题保留在消息正文。
- Markdown 中的 HTML、危险链接和自动加载的远程图片不可直接执行或加载。

**诊断状态：**

| 值 | 文案 | 前端含义 |
| --- | --- | --- |
| QUEUED | 等待执行 | 已受理，等待开始 |
| RUNNING | 诊断中 | 可持续追加回答与证据 |
| COMPLETED | 已完成 | 本轮执行结束，不代表现场问题已经解决 |
| FAILED | 失败 | 展示原因与已有证据 |
| CANCELLED | 已取消 | 保留取消前内容 |
| TIMED_OUT | 超时 | 标明结果可能不完整 |
| INTERRUPTED | 已中断 | 展示中断说明，不自动重跑 |
| LIMIT_REACHED | 达到步数上限 | 标明结果可能不完整 |

诊断状态与连接状态分开展示。断线、重连、刷新不得自动创建第二轮诊断；模拟恢复后按事件标识去重，保留末尾证据。需要一个可重复演示的断线恢复场景。

**证据区：**

- 提供全部、配置、日志、文档四类筛选；切换诊断恢复为“全部”。没有匹配证据时给出空状态。
- 展示应用信息、生效配置、近期日志、下游健康、文档引用、Excel 查询结果等证据。
- 工具证据显示名称、状态、时间和可展开原始结果；普通阅读先看到关键摘要。
- 文档引用展示标题、适用产品版本、章节或页码、片段标识、内容。管理员可查看原文和修订原件；普通用户看到本轮可见片段与权限说明。
- 若展示检索相关性分数，文案注明它不是结论置信度。
- Excel 证据显示 Sheet、修订来源、查询语句、结果表格和是否截断。
- 显示本轮耗时及输入、输出 Token；未报告用量不能显示为已经确认的零消耗。

**历史与归档：**

- 最近诊断显示问题摘要、状态、日期；管理员额外看到人员或应用归属，缺失归属显示“历史未归属”。
- 点击记录恢复对应会话和轮次；新建会话恢复完整空状态。
- 归档作用于整个会话，运行中的会话不可归档。操作成功后从最近诊断隐藏，保留问答、证据与用量。
- 已归档会话禁止续聊。管理员查看其他账号或历史未归属记录时，输入区说明需要新建自己的会话。

### F03 处理结果

位于当前诊断轮次下方或可明确打开的详情面板。执行终态与人员结果分别展示；运行或排队时显示“诊断结束后可回填”。尚未回填是独立状态。

| 字段 | 内容与限制 |
| --- | --- |
| 处理结果 | 已解决、部分解决、未解决、无法确认；新表单默认无法确认 |
| 处理措施或未处理原因 | 最多 4000 字符 |
| 验证说明或缺少的验证信息 | 最多 4000 字符 |
| 剩余问题 | 最多 2000 字符 |
| 本次变更理由 | 最多 1000 字符；后续修订必填 |
| 处理后的人工验证动作 | 最多 2000 字符 |
| 处理后的人工观察结果 | 最多 2000 字符 |
| 人工观察时间 | 明确时区，数据使用 UTC；可用友好的时间控件表达 |
| 补充诊断事件 | 可选，只能关联本轮事件 |
| 关联修复证据 | 管理员可选，只能关联同一来源诊断 |

**状态校验：**

- 已解决：必须具备处理后的独立验证。
- 部分解决：必须具备处理后的独立验证，并填写剩余问题。
- 未解决：说明处理措施或未处理原因，并填写剩余问题。
- 无法确认：明确缺少哪些验证信息。
- 独立验证可以是完整人工观察，或已应用且验证通过、结果明确的关联修复证据。诊断前故障日志、模型建议或“动作已受理”不能单独证明解决。
- 人工观察不得早于已知诊断终态，不能超过当前时间五分钟。错误显示在对应字段附近。

保存后显示确认人、时间、状态、内容和修订号。历史修订可查看，不可被新保存覆盖。版本冲突保留本地输入并提示重新核对；响应丢失进入原请求恢复区。

管理员可从已回填的结果点击“导出脱敏评测来源”。普通用户不显示该入口及管理员专用修复详情。已归档诊断仍可按原权限查看与修订处理结果，不因此恢复续聊。

### F04 知识文档

**页面结构：** 上传表单、文档列表、文档修订与处理详情、最近上传记录、检索验证。复杂详情可以使用侧面板、页内展开或子视图。

**上传表单：**

| 字段 | 规则 |
| --- | --- |
| 文档标题 | 必填，最多 180 字符 |
| 适用产品版本 | 必填，最多 30 字符；默认示例 2.0；通用资料使用 `*` |
| 所属系统 | 必选；上传同一文档新修订时保持归属 |
| 修订说明 | 选填，最多 1000 字符 |
| 文件 | `.md`、`.pdf`、`.xls`、`.xlsx`；大小上限 20 MiB；PDF 需为文字型 |
| 每片字数上限 | 整数 100–8000，默认 100 |
| 重叠字数 | 非负整数，默认 10；不得超过“每片上限减 10” |
| Excel Sheet 序号 | 可选，从 0 开始，逗号分隔；空值表示全部 |
| Excel 表头行号 | 0–1000；0 表示首个非空行，其他值从 1 开始 |
| 先预览列类型 | 可选；勾选后进入预览确认流程 |

产品版本与文档修订号是两个字段。分片重叠不跨章节或 PDF 页。纯前端只读取文件名称、类型和大小用于校验，解析及索引结果使用固定模拟数据，无需实现文件解析器。

**列表与动作：**

- 显示标题、产品版本、文件名、片段数或表格数据标识。
- 解析、关键词索引、向量索引分别显示状态，不能合并成一个“全部成功”。
- 操作包含查看版本与处理记录、上传新修订、重建向量、删除；Excel 不提供文本向量重建入口。
- 重建向量要求向量服务已配置且关键词索引已完成，否则禁用并解释。
- 上传显示保存原件、已受理、重复复用、处理中、完成、失败等状态。受理不等于处理完成。
- 删除后表示资料停止参与检索；原件及索引清理可以继续显示为处理中。
- “导入示例文档”添加合成示例记录，重复点击不无故产生重复文档。

**修订详情：**

- 按修订切换原件、说明和处理批次；保留旧修订。
- 批次展示时间、参数、片段或行数、状态、错误和任务列表。
- 任务展示类型、已处理数量、尝试次数、下次重试时间和执行历史。
- 失败、等待条件、等待自动重试的任务可显式重试。
- 支持使用原件重新分片或重新导入，形成新批次；不覆盖历史。
- 原件缺失时显示补传入口及“内容须与历史摘要一致”的说明，支持模拟核对失败。
- 原文面板包含位置、片段标识和正文，具有明确关闭入口。

**Excel 子流程：** 展示 Sheet、行数、表头位置、原始表头、查询列名、列类型及最多五条样例。类型选项为文本、整数、精确小数、日期、日期时间、是/否；调整后点击确认导入。已就绪的数据支持查询输入，示例为 `SELECT * FROM data LIMIT 20`。查询只做模拟，提供正常结果、空结果、超出只读范围、查询失败和结果截断状态。

**检索验证：** 输入查询内容和适用版本，查询内容最多 2000 字符。结果展示引用片段及其版本、位置与来源；提供无结果和失败状态。不把不适用的历史版本展示成当前版本依据。

向量未配置时，上传、处理和关键词检索仍能演示。已经选择向量调用的失败应显示真实的模拟失败，不悄悄改成关键词成功。后台进度刷新不得覆盖用户正在编辑的导入参数或查询草稿。

### F05 项目约束

**结构：** 添加表单与已确认约束列表。

字段为所属项目、适用系统、适用环境、约束内容和人工确认复选框。项目必选；系统可选“整个项目”；环境可选“整个系统或项目”；内容必填，最多 1000 字符。

下级选项随上级联动，不允许保留属于其他项目的系统或环境。只有勾选“我已确认这项约束适用于当前项目”才能保存。

列表显示内容及适用范围，支持删除。删除后新诊断不再加载该约束，历史诊断保留当时快照。示例内容：“变更需在维护窗口内由实施负责人执行。”

不得根据助手回答自动新增约束。需要空列表、保存中、保存成功、失败保留输入、删除反馈状态。

### F06 示例环境

此页明确标注 OrderBridge 是自建合成环境。

**场景选项：** 升级后配置未迁移、下游不可用 503、凭据错误 401、历史文档版本不适用、日志来源不可用、文档干扰指令测试、健康环境。

**操作：** “切换并发起同步”“创建修复提案”“发起一次同步”。纯前端执行模拟状态变化：切换后更新环境事实与日志，说明原示例日志被替换。诊断运行期间禁止改变当前示例环境。

**环境事实：** 展示应用和版本、生效路径、下游响应、近期同步日志等合成信息，可保留原始结构化数据展开区。创建修复提案进入 F13 的预览，不直接把环境改为健康。

为文档干扰场景显示需要对应测试资料的说明；前端演示可以直接关联预置材料。

### F07 用量分析

**筛选：** 今天、近 7 天、近 30 天、近 90 天；开始日期、结束日期、按天或按小时、更新图表。默认近 7 天，范围包含首尾且最多 90 天。明确使用 UTC 统计。

**概览：** 已报告总 Token 及输入输出拆分、会话数与诊断轮数、平均每轮 Token、已完成诊断数。存在未报告用量时突出计量缺口。

**四类图表：**

1. Token 用量分布：按时段展示输入与输出的堆叠柱状图。
2. 累计用量：从筛选起点累计的折线图。
3. 高消耗会话：前五个会话的横向图，可点击回看。
4. 每轮平均消耗：按时段展示折线，无诊断的时段留空。

同时提供分时精确明细和会话 Token Top 20。点击排行进入会话回看，展示逐轮问题、回答、状态、时间、Token、耗时和证据，并可回到图表。会话回看包含该会话的全部历史，不限于当前筛选日期。

**统计口径：** 已报告总 Token = 输入 + 输出；平均每轮 = 已报告总 Token / 全部诊断轮数。只表示对话模型已报告消耗，不包含向量用量和费用；执行完成率不是答案正确率，Token 多不表示质量高。归档会话继续参与统计。

需要无数据、部分用量缺失、日期非法、数据读取失败和图表组件不可用状态。图表失败时仍可查看数值表格；改变筛选后所有指标、图表与排行使用同一份数据。

### F08 模型配置

使用两个相互独立的表单：对话模型、向量服务。宽屏可并列，窄屏上下排列。

**字段与功能：**

- 服务商：覆盖当前的百炼、DeepSeek、OpenAI、自定义兼容接口；向量表单仅显示适用的服务商，并增加关闭选项。
- 模型 ID：可手填，也可“获取可用模型”后按关键字筛选和选择。
- 接口基础地址：可编辑；模拟合法和非法地址校验。
- API 密钥：隐藏输入，不回显已有值；通过“已配置”“未配置”表达状态。
- 对话模型额外提供推理等级：默认、none、minimal、low、medium、high、xhigh、max、ultra；注明支持情况由模型与服务商决定。
- 独立保存、恢复文件配置、重新读取配置，以及“当前使用界面保存配置或文件配置”的来源说明。

**交互规则：**

- 服务商和地址不变时，密钥留空表示保留；另设明确的清除密钥操作。
- 更换服务商或地址后，不沿用旧密钥，不把旧密钥填入新端点。
- 获取目录只改变可选模型，不自动保存表单；获取失败后仍允许手填模型 ID。
- 保存一个表单保留另一个表单的草稿；切换菜单保留尚未提交的编辑。
- 活动诊断期间禁用保存并说明原因。版本冲突时保留输入，提示重新读取核对。
- “配置已保存”与“服务连通性已验证”分开；纯前端不会验证真实服务。
- 关闭向量服务后显示关键词检索说明，保留既有文档和模拟索引；更换向量模型后提示到知识文档重建。

需要目录加载、空目录、无匹配、权限错误、不支持目录、超时、保存中、保存失败、配置冲突、已关闭状态。演示输入中的密钥不写入浏览器持久存储或导出文件。

### F09 用户管理

**创建字段：** 用户名 3–32 位字母数字下划线；初始密码 12–128 字符；角色为普通用户或管理员，默认普通用户。

可见帮助说明两类账号的访问范围。提交成功清空用户名和初始密码，刷新列表并提供成功反馈。列表显示账号、角色、创建时间等已知信息，密码不进入列表。

需要用户名重复、格式错误、创建中、失败保留可继续编辑的表单、空列表状态。不增加编辑角色、封禁、删除用户、重置密码等现有页面未提供的管理动作。

### F10 企业接入

内容较多，允许通过页内分组、标签或分步布局提高可读性，但不能省略以下范围。

**A 项目、系统与环境**

- 左侧或顶部显示三级资源结构：项目 → 系统 → 环境。
- 支持新建与选择资源；表单包含所属资源、稳定编码、名称、资源状态。
- 编码以小写字母开头，后续为小写字母、数字、下划线或连字符，最多 64 字符；名称最多 160 字符。
- 系统额外包含产品标识，最多 64 字符；环境额外包含预期产品版本，最多 30 字符。
- 创建后编码、归属及系统产品标识固定；资源状态为可用、停用、归档。
- 停用阻止新诊断；资源归档不可恢复，历史仍保留。已归档资源不允许继续编辑。
- 保存模拟版本冲突时保留编辑并提示核对。

**B 系统资料外发策略**

选中系统后显示两项独立开关：允许资料进入对话模型、允许资料进入向量服务。新系统默认关闭；说明涵盖该系统文档及适用项目约束。保存后显示反馈，不把策略改变解释为已运行诊断权限扩大。

**C 环境只读连接**

- 选中已保存的环境后显示基础地址、批准的精确目标 IP 列表、现场访问凭据。
- 凭据仅写入，保存后清空；列表不回显原文。
- 应用信息为必需能力，可额外勾选有效配置、近期日志、下游健康。
- “允许读取哪些能力”和“允许把哪些事实发送给模型”分开设置。
- 保留“本地合成回环 HTTP”选项及企业模式拒绝说明；只演示校验。
- 流程为保存新草稿 → 测试该修订 → 测试通过 → 环境空闲时启用。
- 列表分别显示连接状态、测试状态、修订号、测试时间和失败原因。测试未通过或已过期不能启用。

**D 人员授权**

选择用户、授权范围和授予或撤销。范围分为所属项目成员、当前环境访问。普通用户必须同时具备项目成员资格与环境授权才能看到可诊断目标；前端模拟数据应能展示这项联动。

**E 业务系统调用应用**

表单包含所属项目、应用编码、应用名称、可多选的授权环境，以及提交诊断、读取本应用结果、取消本应用诊断三项权限。列表可启停应用、修改权限及环境；编辑时项目与编码固定。应用是独立调用身份，不等同于管理员账号。

**F 应用访问密钥**

选择应用、有效天数 1–90（默认 30）、是否轮换；轮换说明旧密钥重叠最多 24 小时。签发后展示合成密钥一次，并提供“已保存，隐藏原文”。列表只显示编号、状态与到期时间，支持撤销。

切换应用或隐藏后不能重新查看原文；响应丢失只恢复签发状态，不能伪造恢复旧秘密，应引导撤销后重新签发。该区域的模拟数据也不得使用真实密钥。

需要资源为空、无可授权环境、连接测试失败、测试过期、无可用应用、版本冲突和原请求待确认等状态。资源变化应联动诊断目标、文档所属系统及项目约束的选项。

### F11 / F12 外部评测边界与来源导出

评测中心和案例库属于独立项目，不在本原型中创建页面、实验、模型档案或审阅记录。保留原编号便于核对历史需求，当前导航不展示这两个入口。

来源导出放在 F03 人工处理结果区域：管理员填写脱敏问题和摘要，核对最终预览，明确确认后下载 JSON。未保存、无人工结果、来源修订变化或未确认时阻止导出；输入约束以[来源接口](api.md#处理结果与来源导出-api)为准。

模拟包关联确切的处理结果修订和固定请求编号，只包含人工填写的有限脱敏字段，不自动带入原回答、附件、账号或配置秘密。再次查询原请求和下载返回同一包；修改结果后须另行确认新包，历史包保留。

提供导出后响应丢失的分支：保留编号和输入，刷新后查询原请求，不自动生成新包。可选外部首页只作为离开当前工作台的入口，不共享登录、密钥或浏览器恢复槽；未配置时说明暂无外部入口，不影响诊断和来源下载。

### F13 修复中心

只实现 OrderBridge 2.0 路径迁移这一个固定合成动作。不得出现任意脚本、SQL、命令执行框或自动批准功能。

**列表：** 提案名称、状态、审批人、应用和验证结果、创建时间；支持状态筛选、分页和新建。

**提案预览：** 展示动作、是否适用、实例、环境修订、生效路径、变更前后差异和影响。字段为名称（必填，最多 120 字符）、理由（必填，最多 1000 字符），可带来源诊断。条件不适用时禁用创建。

**详情与动作：**

- 展示提案人、来源、理由、修订、提案截止时间、审批人及审批窗口。
- 状态包括待审批、已批准、执行中、已结束、已驳回、已撤销、已过期、环境已变化。
- 根据条件启用批准、驳回、撤销、执行已批准修复、核查原执行、人工结束未决记录。
- 驳回与人工结束未决记录必须填写理由。
- 旧提案过期或现场发生变化后不能继续执行；可重新采集并创建新提案。
- 执行成功最多发生一次，重复点击或页面刷新不生成第二次执行。

**结果：** 配置应用和执行后验证分栏显示。前者包含应用事实、操作编号、时间及修订；后者包含验证事实、新请求编号、路径、HTTP 状态、接受结果和验证时间。

至少覆盖未应用、已应用且验证通过、已应用但验证失败、结果未知、人工结束未决。未知状态不能按当前配置推断为成功；人工结束仍保留不明事实。审批与执行审计按时间展示，可展开原证据、加载更多；支持 JSON 和 Markdown 导出，并保留示例环境场景操作记录入口。

### F14 飞书机器人

**连接状态：** 未启用、正在连接、已连接、重新连接、异常、已停止。说明当前仅支持文字私聊，以及工作台记录与消息投递的关系。实际凭据配置不在本次前端实现范围内。

**账号绑定：** 选择已有用户，生成合成绑定命令，显示十分钟有效期和仅使用一次的说明。命令由人员通过可信渠道交付；页面不自动发消息。状态包含等待绑定、已绑定、已过期、已撤销，支持撤销。

绑定命令已使用、过期或撤销后清除原文。刷新失败时保留已有可见内容并说明状态可能过期。

**最近消息：** 显示账号、时间、请求编号、诊断受理状态，以及绑定提示、受理提示、诊断结果各自的投递状态和尝试次数。

受理状态包括待受理、等待诊断结果、已生成回复、绑定失效；投递状态包括待投递、已送达、重试耗尽待核查、恢复窗口超期待核查、绑定失效停止投递。已生成回复不等于已送达。投递未知时提示先核对会话，不提供盲目重复发送。

## 4 全局交互与状态规范

### 4.1 通用状态

每个数据区域至少考虑加载、空数据、正常、失败、刷新失败、无权限。表单至少考虑未修改、编辑中、字段错误、提交中、成功、失败和冲突。列表刷新失败时保留旧数据，明确说明它可能不是最新状态。

按钮必须有可观察结果：进入详情、打开表单、改变模拟数据、下载文件或展示具体不可操作原因。禁用按钮提供解释；不以无响应按钮或统一“操作成功”提示代替流程。

耗时操作防重复点击；页面切换后，上一页面的迟到结果不能覆盖当前选中记录。用户编辑时，自动进度刷新不能夺走焦点或重建整个表单。

### 4.2 草稿与恢复

- 菜单切换保留有意义的表单草稿；同一记录草稿按记录标识隔离。
- 已保存的模拟记录在刷新后保留；退出账号后不把前一个账号的临时数据显示给下一个账号。
- 处理结果、来源导出、修复执行及企业管理等操作，需要演示提交后响应丢失。
- 结果未知时显示原请求编号，保留原操作和原始输入；提供“查询原请求”和允许范围内的“重试原请求”。
- 查询失败、未找到或登录失效都不能直接解释为操作没有发生；不得自动换编号重新提交。
- 刷新只恢复页面与查询，不自动触发新的写入或执行。
- 敏感字段不写入持久恢复槽；密钥原文丢失后只恢复状态。浏览器存储不可用时说明刷新后的恢复限制。

这里要求的是前端交互与模拟状态机，不要求实现真实分布式幂等服务。

### 4.3 归档与删除的差异

| 操作对象 | 交互结果 |
| --- | --- |
| 诊断会话归档 | 最近列表隐藏、禁止续聊；历史、用量和处理结果保留；本次不增加会话恢复入口 |
| 企业资源归档 | 不可恢复，保留历史，不允许继续编辑和创建新诊断 |
| 文档删除 | 停止检索，显示后续清理状态；不借此删除历史诊断证据 |

### 4.4 可访问性与响应式

- 所有输入有可见标签；错误与帮助文字对应到具体字段。
- 可用键盘完成导航、表单、列表操作和弹窗关闭；焦点清晰，关闭弹窗后返回触发位置。
- 当前导航、选中的标签和正在处理状态具有明确语义，不能只依赖颜色。
- 主要成功和进度变化适度播报；避免逐字流式输出持续干扰读屏。
- 长日志、编号、代码和表格局部换行或滚动，不撑宽整个页面。
- 至少检查 1440×900、1024×768 和 390×844 三种视口。
- 手机下可使用折叠菜单、抽屉或上下布局；所有管理入口可到达，不能沿用旧布局中固定的菜单数量。
- 对话、证据和人员处理结果都必须可滚动到达，不能因固定高度把底部表单裁掉。
- 动效用于反馈状态，遵循减少动态效果偏好。

## 5 视觉设计要求

界面应适合长期阅读中文诊断、表格和日志。优先表达内容层级、当前状态和下一步动作，避免将后台做成宣传首页。

可参考当前浅色背景、深色文字和低饱和绿色主操作；允许提出其他完整视觉方案，但同一应用中的颜色、间距、字体、状态、按钮和表单保持一致。

建议沿用以下信息组织，而非固定像素：

- 诊断页让回答与证据相邻，主阅读列不过宽。
- 管理页让创建或编辑与已有记录明确分区。
- 企业接入使用层级资源导航，复杂表单分组。
- 用量分析图表与精确数据并存。
- 修复差异、实验比较使用并排对照，窄屏上下排列。
- 专业编号、摘要、原始 JSON 放在可展开的详情中；列表优先显示中文名称、状态和下一步。
- 成功、失败、警告、运行中和未知状态使用不同视觉表达，并始终配有文字。

无需品牌宣传图、插画、头像照片、动画背景或额外营销内容。不得用大面积留白挤压诊断正文、证据与表格的可用空间。

## 6 模拟数据与连续演示

### 6.1 最小数据覆盖

以下是本次前端比较新增的统一数据要求。全部使用合成名称、内容和标识，不复制本机账号、私有文档、日志或密钥。

| 数据 | 最低覆盖 |
| --- | --- |
| 用户 | 1 个管理员、2 个普通用户，可分别演示本人和他人记录 |
| 资源 | 至少 2 个项目、2 个系统、3 个环境，覆盖可用、停用、缺少授权 |
| 会话与诊断 | 至少 4 个会话、8 轮诊断，覆盖多轮、归档、失败、取消、超时、未报告 Token；运行状态可通过新任务触发 |
| 文档 | 至少 5 项，包含 Markdown、PDF、Excel、多修订、处理失败、向量未配置和旧版本资料 |
| 约束 | 至少 3 条，覆盖项目、系统和环境范围 |
| 用量 | 连续 7 天以上，图表、明细、排行与诊断数据一致；包含无诊断时段和用量缺失 |
| 处理结果 | 尚未回填、已解决、部分解决、未解决、无法确认及至少一组修订历史 |
| 来源导出 | 未确认、已确认、版本冲突、原请求待核实与历史不可变包 |
| 修复 | 待审批、已批准、验证通过、验证失败、未知结果、过期或现场变化 |
| 企业接入 | 测试成功和失败的连接修订、可用与停用应用、有效和撤销密钥 |
| 飞书 | 已绑定和过期绑定、回复已生成但未送达、投递结果未知 |

维护共享的模拟数据源，禁止把每个页面做成互不相关的静态示例。统计按同一组诊断数据计算；新增记录、归档、授权和来源修订应影响相关页面。

### 6.2 标准演示主线

1. 使用管理员进入，选择“演示项目 / OrderBridge / 测试环境 · 2.0”。
2. 使用示例问题：“升级到 2.0 后订单同步持续失败，请查询当前环境，核查适用文档，给出有证据的原因分析和人工处理建议。”
3. 模拟排队与流式回答，依次出现应用信息、生效路径 `/v1/orders`、HTTP 410 日志、适用的 2.0 迁移说明。
4. 回答指出版本与路径不匹配，给出迁移至 `/v2/orders` 的人员操作建议，并提示需要新的业务请求验证。此时仅显示诊断完成，处理结果仍未回填。
5. 管理员进入修复提案，查看差异、填写理由、批准，再显式执行；模拟得到应用完成及独立 HTTP 200 验证。
6. 返回原诊断回填“已解决”，关联处理后验证，生成第一条结果修订。
7. 打开来源导出，填写脱敏问题与摘要，核对预览并确认，下载合成 JSON。
8. 修改人工结果形成新修订，再次查询原导出，核对旧包保留且新导出需重新确认。
9. 在用量分析定位该会话，回看问答；归档后最近列表隐藏，统计仍保留。

同时保留一条失败分支：修复已应用但验证失败，不自动填为已解决；以及一条未知分支：提交后响应丢失，刷新后查询原请求，记录和执行次数不增加。

### 6.3 演示控制

在演示说明或独立演示控制入口中提供切换账号、首次初始化、模型未配置、断线、提交结果未知和重置合成数据的方法。此入口应与正常业务导航区分，避免被理解成真实产品功能。

默认打开即有完整可浏览数据。模拟异步有可观察的中间状态且能在短时间结束，不要求等待真实诊断时长。导出按钮生成实际可下载文件，内容来自当前模拟记录，并注明“合成演示数据”。

| A25 | 外部入口 | 未配置时诊断和下载仍可用；已配置只进入独立项目，不共享凭据 |
