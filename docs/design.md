# 界面设计

SupportOps 使用白色与灰蓝色正文面板、深绿色导航和低饱和绿色操作色。诊断页面围绕问题、回答和证据组织阅读；后台页面围绕表单、记录和处理状态组织操作。产品范围见 [产品说明](product.md)，权限规则见 [用户系统](users.md)。

## 样式来源

工作台先加载 [styles.css](../src/main/resources/static/styles.css)，随后加载业务模块样式，再由 [workspace.css](../src/main/resources/static/workspace.css) 统一外壳与响应式布局，最后由 [workbench-theme.css](../src/main/resources/static/workbench-theme.css) 定义工作台组合主题。主体面板采用 Gemini 参考成果的灰蓝背景、白色对话卡片、顶部目标选择与紧凑表单；菜单、深绿色侧栏、数值状态卡片与语义徽标采用 WorkBuddy 参考成果的视觉规则。主题以现有真实数据和操作为基础，不复制参考成果中的合成状态。企业接入分区样式位于 [enterprise.css](../src/main/resources/static/enterprise.css)。登录页使用基础与账号样式。

| 工作台要素 | 当前定义 |
| --- | --- |
| 页面与导航底色 | `--canvas: #f8fafc`；导航由 `#1c4537` 到 `#14342a`，独立于正文背景变量 |
| 操作色与浅底 | `--accent: #356350`、`--accent-soft: #e1ede6` |
| 辅助文字与边线 | `--muted: #526174`、`--line: #e2e8f0`；导航辅助文字使用 `#b9cfc3` |
| 正文字体 | 系统中文无衬线；日志、SQL、原始标识使用等宽字体 |
| 诊断正文 | 桌面与手机 14px、至少 1800px 视口 15px，行距 1.85 |

颜色辅助识别状态，阶段名、状态文字与错误说明必须独立可读。图标与图表库由应用本地提供，来源见 [前端依赖](../src/main/resources/static/vendor/README.md)。

## 页面结构与响应式布局

桌面外壳最大宽度 1760px、侧栏宽度 252px，超宽屏居中。侧栏上部为客户工作区、下部为后台管理；普通用户只显示客户工作区，管理员显示全部菜单。导航操作至少高 44px，历史区域与菜单中段可分别滚动，品牌与部署信息保留在菜单上下两端。顶部上下文栏同时标示所属区域、当前用户名、角色与退出入口。

诊断页左侧为对话，右侧证据栏占约 32%、最小宽度 300px；消息最大宽度 860px。诊断目标位于对话列顶部，选择控件通过 `form` 属性仍关联原诊断表单；底部输入区占满对话列，按问题描述、检索选项与发送操作排列。桌面对话和证据在按视口分配的区域内分别滚动；用户消息右侧显示深绿色气泡，助手消息使用白色细边框卡片。诊断区域最小高度 620px，处理结果长表单通过正文外层滚动访问，不挤压对话区域。标签和帮助文字始终保留在对应控件附近。用量统计使用独立数值卡片，运行中、完成、失败和取消分别采用蓝、绿、红与中性色，并保留状态文字。管理页面使用表单与列表分区；模型配置为两个独立表单，文档详情在上传表单与资料列表下方展开。运行信息页脚位于全部业务页面之后。

| 视口 | 布局变化 |
| --- | --- |
| 不超过 1150px | 诊断与基础管理分区改为单列，证据位于对话下方；数值状态卡片改为两列 |
| 不超过 1080px | 导航改为由顶栏菜单按钮打开的抽屉，正文使用完整宽度 |
| 不超过 1050px | 对话和向量配置表单改为单列 |
| 不超过 680px | 顶栏身份信息换行，输入区目标标签与控件垂直排列，页面横向留白 16px |

顶栏最小高 56px，桌面上下留白 12px，手机 14px；身份文字允许换行。宽表在独立容器内滚动，长文本在单元格内换行，避免撑宽整页。短窗口允许侧栏滚动以访问全部入口。

## 诊断、证据与历史

- 新建会话恢复完整问题引导；诊断标题最多两行，完整问题保留在消息中。
- 公开回答使用 Markdown 渲染，流式更新保留已成形内容；关闭原始 HTML、危险链接和图片自动加载。
- 证据提供全部、配置、日志、文档四类筛选，切换会话恢复全部分类；引用展示标题、版本、位置和片段标识，工具原始结果可展开核对。
- 执行中、完成、取消、失败、超时和中断分别显示。未完成草稿不伪装成最终结论；重新连接不重新提交诊断。
- 归档以整个会话为单位，执行中不可操作；失败保留记录并允许重试，成功隐藏侧栏记录，问答、证据和用量仍保留。
- 归属优先显示用户名，无归属记录显示“历史未归属”；查看他人或历史未归属会话时说明需新建自己的诊断。

## 账号入口与管理

登录表单居中、最大宽度 440px，横向留白 16px、纵向留白 32px，主按钮至少高 44px。首次创建管理员与登录共用单列表单，通过标题、说明和按钮区分；状态读取或提交期间禁用主按钮。

用户名与密码具有可见标签，并关联格式与长度说明。密码使用隐藏输入，首次创建使用新密码自动填充语义；错误保留在表单警报区。管理员创建用户默认普通角色，字段说明明确两类账号的访问范围；成功后清空用户名和初始密码，更新用户列表并提供状态播报。宽屏创建表单与用户列表分列，窄屏按此顺序排列。

## 后台操作反馈

- **企业接入：** 资源树与编辑区分列，窄屏上下排列。编辑区分为“资源设置”“连接与授权”“应用与密钥”，切换分区保留未保存草稿；选择资源后返回资源设置。连接与人员授权只在环境资源下显示，系统资料策略只在系统资源下显示。固定请求恢复入口位于分区之外；恢复得到一次性秘密时自动显示应用与密钥分区。
- **模型配置：** 对话与向量分别保存，获取模型目录不保存草稿；密钥不回显，保留、更换、清除有明确说明。保存、恢复与重读共用忙碌状态，另一表单草稿及跨菜单草稿保留。配置状态不代表远程鉴权成功。
- **知识处理：** 适用产品版本与文档修订分别展示。解析、关键词、向量状态独立显示；资料列表先给出名称与状态，修订、批次、任务尝试和参数按层展开。刷新失败说明数据可能不是最新状态。
- **Excel：** 预览展示原表头、受控列名、类型与样例，确认后提交正式批次。结果同时展示 Sheet、修订原件入口、实际 SQL 及截断状态；空结果和失败分别表达。
- **用量分析：** 图表保留对应明细与会话回看入口；无用量报告单独说明，统计结果不表达回答质量或账单金额。

## 可访问性与交互约定

表单保留可见标签和紧邻帮助文字；键盘焦点清晰可见，当前导航设置当前页语义。主要状态使用礼貌级播报，操作错误使用警报语义；删除、归档、配置变更的影响通过文字说明，不仅依靠颜色或图标。

页面提供跳到主要内容的键盘入口。导航抽屉打开时正文不可聚焦，焦点在可见导航控件内循环；Escape、遮罩和关闭按钮均可收起抽屉，并恢复菜单按钮焦点。从抽屉切换页面后聚焦新页面标题；跨断点时清理遮罩和不可交互状态。企业分区标签支持方向键、Home 与 End。

长日志、原文和表格在局部容器阅读；对话框提供明确关闭入口与焦点恢复。减少动态效果偏好下关闭忙碌动画与过渡。设计约定与自动化检查不能替代浏览器验收；已执行检查的范围见 [验证结果与范围](validation.md)。

页面结构与交互实现位于 [index.html](../src/main/resources/static/index.html)、[app.js](../src/main/resources/static/app.js)、[workspace-shell.js](../src/main/resources/static/workspace-shell.js)、[login.html](../src/main/resources/static/login.html) 和 [login.js](../src/main/resources/static/login.js)。外壳模块只处理导航与分区展示，不读取或提交业务数据。
