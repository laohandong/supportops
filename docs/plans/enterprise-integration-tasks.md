# 企业独立部署与系统接入 V1 开发任务及验收

日期：2026-10-04。状态：EI-01至EI-07核心实现已交付，EI-08开发验证与证据已建立，34项矩阵含未覆盖子项，尚未通过完整独立验收。本文与[功能技术设计](enterprise-integration-design.md)共同定义企业接入 V1 的实施和验收契约；实际结果见[开发验证记录](../enterprise-integration-acceptance-20261004.md)。任务存在不等于整项验收通过。

## 执行范围

本版本贯通企业项目与环境、标准只读接入、明确目标诊断、应用 API、管理页面和部署升级。实现阶段按依赖完成必要迁移、代码、修复和隔离验证；任务编号是组织方式，不构成逐项审批停点。

实施覆盖本契约内的迁移、后端、页面、独立样例、发布包和隔离存储验证。现有工作台替换、企业现场与真实模型联调分别按明确运行范围执行；本开发验证不替代企业试点。

执行前读取根 [AGENTS.md](../../AGENTS.md)及两份企业接入方案，检查实际 Git、迁移、运行程序与存储身份。保留现有未提交文件、`.local` 配置、当前工作台和历史容器。不得提交、推送、发布或通过清库解决迁移问题。

保持 Java 21、Maven Wrapper、Node 22、模块化单体与现有 GET/POST 业务接口规则。新代码和测试不用 var，手写类型、方法和构造器维护中文 Javadoc，DTO/VO 同步中文 Schema。Maven 不并发使用共享 target。

## EI-02 资源和数据授权

新增 `project` 模块，按仓库规则组织 entity、mapper、service/impl、dto/vo、controller。实现项目、系统、环境、成员、用户环境授权和只读目标解析。现有 ADMIN/USER 不改名，不构建通用角色引擎。

新增 `integration` 必要持久化，包含连接修订、测试、应用、应用环境授权、访问密钥、固定请求、管理请求回执和审计。`runs` 支持独立应用所有者，目标快照一任务一条，文档和约束有明确归属。

事务中核对项目/系统/环境关系，使用组合唯一、外键、旧版本条件更新与影响行数。所有管理关系由管理员授权，普通用户请求不能写角色、所有者、连接地址或权限。

使用真实隔离 MySQL 独立 SQL 核对迁移结果。准备 V11 合成旧数据，包括普通与管理员问答、无归属历史、归档、事件、未报告用量、文档与 Excel、记忆、飞书绑定、结果/案例/评测和修复历史。升级后保留原 ID 和事实，历史目标明确标记推定。

## EI-03 凭据和企业入口

可恢复秘密与不可恢复访问密钥使用不同存储方式。提供加密、按用途解密、引用、安全描述、撤销、密钥版本和轮换，不提供通用解密 HTTP 接口。

验证 AAD 错误、密文/标签损坏、缺 keyId、主密钥变化、部分轮换、受控重试和旧密钥移除保护。轮换事务与过程允许恢复，失败不以新密钥覆盖未完成旧数据。旧本地设置通过显式停写导入，导入不联网鉴权，不覆盖或删除原文件。

企业模式实现可信 Host/Origin、可信代理、HTTPS Cookie、一次性首次初始化秘密及机器 API 的独立认证。持久化单实例 guard 必须先于历史恢复和消费者初始化，异常接管需要核实旧实例退出，不能只等待过期。测试不能仅绕过过滤器调用 Service。内部 MCP 的真实连接和传输凭据保护必须通过真实 HTTP 检查，企业代理禁止该路径。

审计与日志、异常、OpenAPI 示例、配置读接口、快照、备份和评测材料均检查秘密泄漏。修复现有配置采集器，保证企业模式不会把主密钥、setup Secret 或已导入明文源文件打包进普通备份。评测子进程通过受限引用获取冻结凭据版本，不将秘密放入命令参数、公开材料或报告。

## EI-04 标准连接器和接入样例

实现 `DiagnosticConnector` 和固定能力注册器。标准协议使用明确 DTO/Schema，固定路径、受限参数、目标鉴权、响应身份核对、严格超时和大小上限。客户端必须保证解析白名单与实际连接地址一致，保持 TLS 主机名检查。

实现不可变草稿、固定请求测试、分项结果、测试失效与激活。连接测试只访问该草稿已登记的地址和批准能力，日志样本最多 5 条；测试不会发送给模型，不在管理页面返回日志正文和配置值。

独立 Java 样例建议位于 `examples/integration/java-diagnostic-source/`，有独立构建与运行入口，不依赖 SupportOps DemoService。公开样例仅含合成数据和秘密占位符；测试运行时生成实际临时秘密。提供独立 OpenAPI 文件和字段说明，明确权限、脱敏与来源职责。

同一标准协议部署两个样例系统，分别采用不同系统标识、资料和秘密。第二套接入仅增加资源和配置，不能修改诊断核心或硬编码源地址。另做目标 401/403、503、缺能力、错误身份、版本漂移、无效 JSON、正文停滞和跨地址重定向。

## EI-05 诊断和资料范围

以明确 Actor 和目标 DTO 替代引擎的隐式 DemoService 上下文。引擎、资料查询与工具只能收到服务端认可范围，参数传递不使用无类型 Map。

全局容量与环境锁保留实际资源释放边界；映射所有 requireIdle/whenIdle 调用。模拟两个环境的并发诊断与示例修复，证明环境写排他和全局维护保护均成立。正常轮换不篡改运行快照，紧急撤销停止后续工具和外发。

知识查询在召回前按系统、发布关系和版本限定，返回前再查授权与来源。同版本不同系统、通用 `*` 文档、Excel datasetId、约束、历史引用、文档删除及向量配置变化均覆盖。修订和逻辑删除不改变历史引用快照；当前可用资料需通过当前权限核对。

网页每次显式选目标，同会话禁止换环境。原 API 缺省目标保留示例兼容，飞书绑定有管理员设置的默认环境。原评测保持合成边界；企业记录可进入人工候选但不能引导自动现场回放或现有示例修复。

用量按原逐轮事实累计，应用任务具有独立应用维度。用户维度不把应用任务统计为“未知用户”，总量不减少或重复累计。未报告用量继续保留未知标识。

## EI-06 应用 API 和固定请求

实现设计中的 `/open-api/v1` 精确 GET/POST 路由。应用仅能访问本应用任务和已授权环境，普通 Cookie 与后台权限不能用于机器接口。新增 API 文档不得公开真实访问密钥或连接地址。公开事件、引用、证据读取和结果均按固定 VO 投影，并验证页大小、截断标记和游标不跳项。

固定请求采用版本化规范摘要，保留同键异参冲突、相同请求读取、权限重新核对。独立 SQL 验证请求、run、目标快照数量与外键，使用提交后切断连接证明受理响应丢失，不以客户端模拟异常替代已提交事实。

客户端样例保存 requestId 和请求体，恢复查询失败维持 UNKNOWN，404 后仅重发同一请求。文档演示 202、200 重放、409 冲突、429、取消、错误任务和有界事件轮询。V1 不增加自动 Webhook 或应用续聊。

测试密钥失效、过期、轮换、签发响应丢失、应用停用、权限撤销、伪造 owner、跨应用 runId、分页越界和模型未配置。受理事务回滚不留下回执、任务或容量占用；进程在提交后调度前退出，重启仅显示 INTERRUPTED。

## EI-07 页面和企业包

复用现有静态页面组件和固定请求恢复机制。管理员能够创建项目到启用环境、授权用户和应用；普通用户只见可用目标与本人记录。资源选择显示项目/系统/环境完整名称，生产环境明确标识，不能靠文本问题猜目标。

覆盖草稿、未测试、测试失败、测试过期、版本冲突、已启用、停用、权限撤销、容量不足和未知请求。秘密输入支持写入/保留/清除语义，首次密钥显示明确一次性；回执查询不回放秘密。

新增独立企业 Compose 和应用镜像入口，保留根本地开发 Compose。包内固定镜像版本或 digest，提供 SHA-256 清单、Secret 挂载模板、企业域名/CA/模型策略和初始化说明。镜像不内置真实或公开合成运维密码，不自动创建开放数据库监听。

安装验收使用全新目录和专属依赖：无需现场 Maven 构建即可初始化和接入样例；离线包不运行时下载镜像、脚本或模型。自有存储备份边界与专属 Compose 备份边界分别说明，不能套用同一已通过结论。

## 构建和证据交付
