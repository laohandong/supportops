# 企业系统接入

SupportOps 企业版采用单企业独立部署。企业管理员在同一实例内管理项目、系统和环境，诊断在服务端捕获明确目标；应用调用与人员账号分别授权和计量。本功能采用现有模块化单体与静态工作台。

## 首次接入

1. 按[独立部署说明](enterprise-deployment.md)安装，在 HTTPS 页面输入部署者持有的一次性初始化秘密，创建管理员。
2. 在“企业接入”创建项目和系统，再创建环境。系统的产品标识与环境版本必须与现场标准源响应一致；名称用于展示，编码创建后固定。
3. 在现场系统部署只读诊断源，配置 HTTPS、受信任证书与专用 Bearer。协议和独立 Java 合成样例见[标准源协议](enterprise-source-protocol.md)。
4. 为环境保存不可变连接草稿。管理员登记精确 IP 白名单和能力；APP_INFO 必需。允许进入模型的能力是单独批准的子集。
5. 测试草稿，核对分项结果，再启用。测试只访问固定能力，不调用模型，不在界面返回配置值或日志正文。通过测试超过30分钟，或资源身份/版本改变，需要重新测试。
6. 先赋予项目成员资格，再授权环境。普通用户只能选择已启用且获准的目标，读取本人诊断。管理员可以读历史记录；停用不会删除历史事实。
7. 配置对话模型。企业安装默认停用模型与向量服务；模型密钥加密保存。系统文档及项目约束的对话外发、向量外发分别批准。

网页提交必须选择目标，同一对话不能切换环境。目标来自资源配置，不从问题文本推断。历史未捕获目标的记录显示“历史示例目标（推定）”。飞书的绑定默认环境由管理员指定；企业包默认关闭飞书。

## 资料范围

上传文档必须选择所属系统，后续修订保留归属。同版本的不同系统不共用文档，通用版本 `*` 仍限于所属系统。关键词、向量和 Excel 查询在召回前和返回前检查系统与发布关系。项目约束可属于项目、系统或环境三级；只取目标层级适用的约束。

资料管理和关键词检索不要求向量密钥。系统未批准外发时不能把文档或约束加入模型上下文；未批准向量时不能发送分片或问题给向量服务。已经进入向量调用后出现错误会明确报告。人员只能保存明确确认的事实，模型生成的建议不会自动成为项目记忆。

## 应用调用

管理员创建应用，显式授权同项目环境及 DIAGNOSE、READ、CANCEL 权限，再签发访问密钥。完整原文仅在首次成功响应中显示；服务器只保存摘要。签发响应丢失时查询原管理回执，不会回放原文。密钥最多90天，两枚有效密钥上限；轮换旧密钥重叠最多24小时。

调用使用 `Authorization: Bearer <应用访问密钥>`，与 Cookie 会话分离。客户端不提交人员所有者、目标地址或模型配置。所有查询重新核对本应用所有权、密钥和环境授权。

机器API独立OpenAPI定义由实际生成接口提取，仓库位置为 `examples/integration/client/openapi.json`，离线包位置为 `examples/client/openapi.json`；只包含本节八个路径、Bearer鉴权及递归模型引用，不包含后台路由或部署地址。

| 方法与路径 | 语义 |
| --- | --- |
| GET `/open-api/v1/environments` | 当前获准且可用的目标 |
| POST `/open-api/v1/diagnoses` | 固定 requestId 异步受理，首次202，相同重放200 |
| GET `/open-api/v1/requests/{requestId}` | 恢复原回执；确认404后仅重发同键同正文 |
| GET `/open-api/v1/diagnoses/{runId}` | 当前持久化状态 |
| GET `/open-api/v1/diagnoses/{runId}/events` | after非负，limit默认100、最大200；nextAfter继续 |
| GET `/open-api/v1/diagnoses/{runId}/evidence/{eventId}` | 安全证据快照，不重新访问现场 |
| GET `/open-api/v1/diagnoses/{runId}/result` | 执行中409，所有终态200，真实状态保留 |
| POST `/open-api/v1/diagnoses/{runId}/cancel` | 要求CANCEL；取消后资源释放前仍占容量 |

最小提交示例：

```json
{"requestId":"11111111-1111-4111-8111-111111111111","environmentId":"22222222-2222-4222-8222-222222222222","question":"检查同步依赖状态","lexicalOnly":true,"externalReference":null}
```

同一应用同 requestId 异参返回409。其他应用无法读取该任务；请求查询失败保持 UNKNOWN，不产生新键。已提交任务断线后继续通过回执、事件和结果恢复，重启后的未完成任务显示 INTERRUPTED，不自动重跑。

初始额度：每分钟30次提交、120次读取、2个未释放任务。管理员可设置提交1至300、读取1至1200、活动任务1至4，仍受全局和每环境排他约束。429响应含 Retry-After。HTTP重放计频率，不重复累计模型任务和Token。

可运行客户端位于 `examples/integration/client/diagnosis-client.mjs`。设置 `SUPPORTOPS_API_ORIGIN`、`SUPPORTOPS_APPLICATION_SECRET_FILE`、`SUPPORTOPS_ENVIRONMENT_ID`、`SUPPORTOPS_QUESTION` 和 `SUPPORTOPS_CLIENT_STATE` 后运行 Node22。私有CA用 `NODE_EXTRA_CA_CERTS` 的证书文件。客户端持久化原请求与应用身份，以有界事件轮询读取结果；再次运行读取同一状态。`SUPPORTOPS_CANCEL=true` 请求取消原任务。状态文件可能含诊断结果，应按企业资料保护。

## 边界

现场连接只读，不注册远程 MCP 或任意脚本。配置和日志内容不能扩大服务端工具权限。企业诊断可作为人工结果及候选案例来源，但不能驱动内置示例修复或自动回放企业现场。已存在的合成评测与演示修复仍遵守其独立范围。

功能验证、真实模型效果与企业试点分别记录。独立合成 Java 源及本地模型夹具证明协议与执行边界，不能代表企业现场模型准确率或生产SLA。
