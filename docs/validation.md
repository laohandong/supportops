## 复现与报告

1. 按 [隔离测试与评测部署](deployment.md#隔离测试与评测) 准备三项存储并执行 Maven `verify`、JavaScript 测试与 `--sources-only`。

3. 配置真实对话和嵌入服务后，按 [场景评测](../evaluation/README.md) 运行并填写人工审阅结果；配置完整不代表鉴权成功，退出码 0 不代表质量通过。

Maven 报告生成于 `target/surefire-reports/`，场景报告生成于 `.local/evaluation/`，均为本地生成物。`report.json` 保存执行状态、事件和指纹，`review.md` 用于人工判定；运行日志与含凭据的本地配置应分别管理。

## 发布边界

GitHub Actions 在隔离的 Ubuntu 环境中执行 JavaScript 测试、真实存储依赖下的 Maven 验证与打包，以及首次启动和六个来源场景检查。每次提交的执行状态、日志与报告见 [Verify 工作流](https://github.com/laohandong/supportops/actions/workflows/verify.yml)，应按提交版本核对结果。

上述自动工程检查不提供外部模型质量结论；2026-09-18 的逐例审阅覆盖修改前后各 18 次诊断，均来自同一组六个合成场景。现有验证不包含最新版本的完整浏览器视觉验收、生产部署、多实例故障演练或压力测试。
