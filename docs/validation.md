## 覆盖的工程边界

- **任务与协议：** 真实本地 HTTP / MCP、模型流式响应与工具调用、取消、超时、终态保护、SSE 游标恢复，以及 Token 事件与累计值一致性。
- **持久化：** 真实隔离 MySQL / MinIO / ES，覆盖上传、原件、修订、分片、关键词与向量发布、失败补偿、版本过滤、删除与历史保留；事务结果使用独立数据库查询核对。
- **账号与记录：** 首次管理员互斥、密码验证、Cookie 与写请求头、普通用户本人记录范围、后台拒绝、会话归档与统计保留。
- **Excel：** 类型与精度、预览、受控 SQL、只读连接、来源行号、查询上限及失败不发布。
- **配置：** Provider 路由与参数、界面优先级、配置冲突、原子保存，以及服务商或地址变化时的凭据隔离。
- **迁移：** 初始化结构、旧数据保留、H2 离线读取与非空目标拒绝。已有环境的升级仍需按 [数据库维护](database.md) 核对实际结构与备份。

对话和嵌入协议测试使用本地 HTTP 夹具，验证请求、响应、失败和状态处理；它们不验证外部平台账号鉴权或模型的自然语言判断能力。接口测试中存在明确的服务替身，不能将其单独当作真实存储验收。

## 可选真实模型检查

2026-09-09 曾使用配套本地 ONNX 权重与 tokenizer，通过 4 项真实推理测试，覆盖中文合成正反例、长候选、取消、超时及取消后复用。这是特定模型与本机的小样本检查；该次真实存储结合精排用例受 Docker 故障阻塞，2026-09-10 完整构建又因未提供模型文件跳过，因此不能声称完整的“真实存储＋本地模型”链路已经通过。

真实对话 / 嵌入服务的六场景质量评测尚未完成。历史单批文档使用真实嵌入服务建索引成功，也不构成检索相关性或诊断准确率证明。模型选择、排序收益、引用支持度、Text2SQL 自然语言准确性与注入抵抗效果均需按 [评测说明](../evaluation/README.md) 单独审阅。

## 复现与报告

1. 按 [隔离测试与评测部署](deployment.md#隔离测试与评测) 准备三项存储并执行 Maven `verify`、JavaScript 测试与 `--sources-only`。
2. 启用真实 ONNX 用例时，按 [本地重排序验证](reranking.md#验证) 提供匹配的模型与分词文件。
3. 配置真实对话和嵌入服务后，按 [场景评测](../evaluation/README.md) 运行并填写人工审阅结果；配置完整不代表鉴权成功，退出码 0 不代表质量通过。

Maven 报告生成于 `target/surefire-reports/`，场景报告生成于 `.local/evaluation/`，均为本地生成物。`report.json` 保存执行状态、事件和指纹，`review.md` 用于人工判定；运行日志与含凭据的本地配置应分别管理。
